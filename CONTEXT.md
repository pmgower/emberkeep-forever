# Glossary

| Term | Meaning |
| --- | --- |
| Character | One alt, keyed `Name-Realm`: class, faction, level, last seen. |
| Roster | The account-wide set of characters and what was last observed about each. |
| Rest observation | What the game reported at one moment: rested XP, XP to level, resting or not, Well Rested rank, time. |
| Rest projection | Rested XP now, the cap, and time until full, computed from the last rest observation. |
| Capped | Projected rested XP has reached the cap; further rest is wasted. |
| Well Rested | Forever Legacy perk, 0 to 5 ranks per character: +4% rested rate and +4% cap per rank. |
| Play-next ranking | Characters below max level: capped first (longest capped first), then by rested XP as a share of the cap. |
| Focus | One way of reading or ranking the roster, shown as a view. Play next is the first; later ones (cooldowns, lockouts, gold) plug in without changing the roster. |
| Snapshot | The items in one location (Equipped, Bags, Bank, Mail) and when they were observed. |
| Alt panel | The panel docked beside the main window that shows one character's snapshots. |
| Outleveled | An equipped item more than 8 item levels below its wearer's level (from level 10). |
| Stale | A snapshot that can only be refreshed at the bank or mailbox, shown "as of" its time. |
