# Kinfolk: Forever

A World of Warcraft: Forever addon that keeps all your alts in one place. The first release tells you
which alt to play next for rested XP; gear, bags, bank and mail views follow.

Type `/kinfolk`. More views (gear, bags, bank, mail) arrive one release at a time; see CHANGELOG.md.

## Development

Needs Lua 5.1, luacheck, StyLua and busted. Run `scripts/check.sh` before pushing; CI runs the same.
